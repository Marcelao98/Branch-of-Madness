# Age 7: The Digital Age

Computers start out the size of rooms, then shrink to fit on a desk, then in a pocket. The internet links them all together, and suddenly the whole of human knowledge is a search away.

In 2005, a programmer named Linus Torvalds gets fed up with the tool his team uses to track changes to their code. So he writes a new one in a couple of weeks and calls it **Git**.

Git remembers every change, lets anyone make a parallel version of history, and lets those versions merge back together.

Somewhere, many years later, someone types `git init` and starts writing a story about dinosaurs, meteors and parallel timelines.
